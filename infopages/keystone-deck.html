03
The Architecture

Three layers.
One working system.

Markdown files + Git — the persistence layer. Files outlast any conversation. Issues, decisions, history, library — all version-controlled
Claude Code (or Gemini CLI) — the agent layer. Reads files, writes files, plans, acts. A command-line AI that works on your documents, not just a chat window
The Agent OS — the OS layer. Bootloader, constitution, reusable skills. Generic infrastructure — shareable like an operating system
04
The Foundation

The Agent OS

Global infrastructure that every project inherits — like firmware for your AI.
BOOTLOADER.md — the first doc every agent reads. Orients, then hands off. Version 0.6 · "You have just come into existence with a blank context window."
usr/lib/practices/ — reusable patterns. Trip planning. Issue tracking. Library maintenance. Like a company wiki, except the AI actually reads it before every session
Policies — cross-project rules. What gets version-controlled. What stays isolated.
INDEX.md — the map. Every charter, every project, its current phase. Updated by the agent at the end of each session

Kernel — status, priority, parent. Scannable at a glance.
History — reverse-chronological. Newest entry always on top.
Children — linked subissues. Root → parent → child → grandchild.
It's a tree — not a flat backlog. Context lives in the hierarchy.

Session Navigation

Cold start in 3 files

The hot index tells the agent exactly what to load — and in what order.
# Orientation sequence (cold start)
 
1. status.md
← one paragraph per sub-project
 
2. history.md (last 3–5 entries)
← what happened recently
 
3. issues/2026/index.md
← open root issues
 
# Then: "What needs attention today?"
Hot index — curated ~15 frequently-used docs, loaded before anything else
Cold index — full B-tree covering all 154+ docs, traversed on demand
No reading the whole corpus. Just the right slice for the task.

Working Style

Dispatches + Focus Days

Two modes of input. One consistent output: the corpus grows.
Dispatches — long stream-of-consciousness input after time away from the desk. The AI extracts: questions being asked, decisions being made, patterns worth hoisting.
Walk-and-transcribe — dictate while walking; AI structures the output. Garage review, CCL debrief, trip planning notes — all started this way
"Days" system — themed focus days: trip day, investment day, gift/card day. Organizes momentum across many open projects without constant context-switching
Approvals — short responses close loops: "yes", "proceed", "looks good." Bill is the Emperor. Thumb up means proceed. Thumb down means stop and ask.
